Contribution statement

Together with my colleague Nils Kovacic, I was tasked with studying and implementing the ARP spoofing detection system proposed in the paper Mohammed found. It proposed using active methods such as sending gratuitous ARP requests and verification via the TCP/SYN protocol to detect a potential ARP spoofing attack. We studied how this system would work and the different scenarios it would face. 

Once I had the necessary knowledge, I proceeded to implement the corresponding code using the scapy library and the use of threads that would allow alerting against possible changes in the network. To do this, I first created a preliminary version that would passively detect the attack by observing MAC addresses changes in entries we already had. Once this phase was completed, we moved on to implementing the detection code for half and full cycles to ensure we didn't accept unsolicited ARP replies. We also added a verification system that would test different common ports to send a TCP/SYN reply to those hosts that responded to our request in a timely manner. Finally, we added the case where an attacker had altered their stack to be able to respond to our verification, although it hasn't been tested yet. Additionally, I worked on transforming the detection system into a prevention system, managing to directly alter the ARP table of our victim host based on the detector's logs. However, due to not achieving the expected results, it was decided to leave it for possible future work.

Likewise, once we had a stable version of the code, I was in charge of proceeding to its corresponding testing phase. By combining it with the code generated for the offensive part, we could verify that it worked as expected.
